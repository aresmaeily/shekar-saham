# الگوریتم‌های رادار بورس

## ۱. متریک‌های پایه تابلو

| متریک | فرمول تقریبی |
|--------|----------------|
| سرانه خرید حقیقی | `(Buy_I_Volume × pl) / Buy_CountI` |
| سرانه فروش حقیقی | `(Sell_I_Volume × pl) / Sell_CountI` |
| قدرت خریدار | `buy_per_capita / sell_per_capita` |
| خالص پول حقیقی | `(Buy_I_Volume - Sell_I_Volume) × pl` |
| نسبت حجم | `tvol / avg_vol_30d` |
| جابجایی حقوقی→حقیقی | `(Sell_N_Volume - Buy_N_Volume) × pl` |

## ۲. امتیاز ورود (۰–۱۰۰) — اولویت اصلی

وزن‌های کلیدی:

1. **حجم مشکوک** (تا ۲۲): `volume_ratio ≥ 2` یا `≥ 3.5`
2. **پول هوشمند** (تا ۲۲): قدرت خریدار ≥ ۲ و سرانه بالا
3. **ورود پول حقیقی خالص** (تا ۱۵)
4. **حقوقی به حقیقی** (تا ۱۰)
5. **شکار در منفی** (تا ۱۸+۶): `plp ≤ 0` همراه حجم/قدرت؛ منفی عمیق پاداش اضافه
6. **فشار تقاضا روی بهترین خرید** (تا ۸)
7. **نزدیکی صف خرید** (تا ۱۰) — بدون دیر رسیدن به صف کامل
8. **بنیادی** (تا ~۱۲): P/E پایین‌تر بهتر
9. **پول داغ / بزرگان** (تا ۱۸)

آستانه هشدار پیش‌فرض: **۶۵** · سیگنال قوی: **۸۰**

### الگوی طلایی مدنظر شما

```
حجم مشکوک
+ قدرت/سرانه خریدار بالا (پول هوشمند)
+ قیمت منفی یا کم‌رمق
+ احتمال حرکت به سمت صف خرید (فشار تقاضا)
+ P/E و بنیادی قابل قبول
→ هشدار ورود زودهنگام
```

## ۳. امتیاز خروج (۰–۱۰۰)

- خروج پول حقیقی
- قدرت خریدار < 0.75
- سرانه فروش در محدوده پول داغ
- برآیند پول داغ منفی
- حجم بالا + خروج پول
- نزدیک/در صف فروش
- توزیع در مثبت (plp>3 و ضعف خریدار)
- خروج بزرگان

آستانه هشدار: **۶۰**

## ۴. پول داغ / پلاس

| سطح | آستانه سرانه (پیش‌فرض) |
|------|-------------------------|
| پول داغ | ≥ ۲۰۰ میلیون |
| پول داغ پلاس | ۱۰۰–۲۰۰ میلیون |

در نسخه زنده بعدی می‌توان از **ریزمعاملات (Trade Detail)** برای تشخیص دقیق سفارش‌های درشت استفاده کرد. نسخه فعلی از **سرانه و ساختار حقیقی** تقریب می‌زند.

## ۵. بازی بازار

سه لایه بر اساس سرانه:

- **بزرگان:** سرانه ≥ پول داغ
- **متوسط:** سرانه در بازه پلاس
- **خرد:** بقیه

بایاس هر لایه بین ۱- و ۱+ (ورود/خروج) محاسبه می‌شود.

## ۶. شکار صنعت

برای هر صنعت:

```
score ≈ avg_plp×3
       + علامت(خالص حقیقی)
       + volume_ratio
       + (buy_power - 1)
       + تعداد کاندید ورود
       + ارزش معاملات
```

## ۸. فاز ۲ — تحرکات بزرگان

هر رفرش یک ردیف در `symbol_ticks` ذخیره می‌شود. برای پنجره W ثانیه:

```
Δnet   = individual_net_value_now - then
Δvol   = tvol_now - then
Δplp   = plp_now - then
Δpower = buy_power_now - then
Δhot   = hot_net_now - then
```

امتیاز از شدت این اختلاف‌ها + همسویی/واگرایی قیمت و پول ساخته می‌شود.

## ۹. فاز ۲ — تابلو کستیک

| شاخص | مفهوم |
|------|--------|
| D⁺ | تقاضا (order book) + قدرت خریدار + نزدیکی صف |
| M⁺ | مومنتوم پول حقیقی و پول داغ (−۱۰۰…۱۰۰) |
| عدد طلایی | سرانه + قدرت + حجم + تقاضا (+بنیادی) |
| کیفیت / درجه | ترکیب طلایی، D⁺، M⁺، entry_score → A+…D |
| ساعت / کراس | pl در برابر pc و تخمین دقیقه تا کراس |

## ۱۰. فاز ۴ — بک‌تست

برای هر نماد روی سری زمانی bar:
1. اگر `entry_score >= threshold` → ورود
2. خروج با اولین رخداد: TP، SL، `exit_score` بالا، یا max hold
3. کارمزد `fee_pct` از بازده کم می‌شود

معیارها: win rate، avg/median return، max drawdown، profit factor، sharpe-like، equity curve.

## ۱۱. فاز ۴ — اختیار (Black-Scholes)

```
d1 = [ln(S/K) + (r + σ²/2)T] / (σ√T)
d2 = d1 - σ√T
Call = S N(d1) - K e^{-rT} N(d2)
```

Greeks: delta, gamma, vega, theta, rho.  
استراتژی‌ها بر اساس entry/exit score تابلو پیشنهاد می‌شوند.

## ۱۲. محدودیت‌ها

- کدال/Trade Detail کامل روی VPS ایران پایدارتر است.
- زنجیره اختیار فعلاً synthetic آموزشی است (نه قیمت بازار آپشن TSE).
- اعلان بدون توکن dry-run می‌شود.
- بک‌تست گذشته ≠ عملکرد آینده.
