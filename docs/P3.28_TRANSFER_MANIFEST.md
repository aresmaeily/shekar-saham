## Git Recovery Notes

1. Extract the backup on the main computer.
2. Run:

```bash
git status
git log --oneline --decorate -8
git rev-parse HEAD
git ls-remote origin refs/heads/main
```

3. If `.git/config` was excluded, restore origin safely:

```bash
git remote add origin https://github.com/aresmaeily/shekar-saham.git
```

or:

```bash
git remote set-url origin https://github.com/aresmaeily/shekar-saham.git
```

4. Push only with secure local credentials:

```bash
git push origin main
```

5. Verify:

```bash
git ls-remote origin refs/heads/main
```

Do not force push unless explicitly reviewed and approved by the project owner.
