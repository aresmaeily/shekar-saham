## ۳. ناهماهنگی‌های سیستماتیک (اندازه‌گیری‌شده)

- **۱۴۸ رنگ یکتا** در ۳ فایل CSS (۲۱۴ مورد مصرف) بدون هیچ design token — پالت غیرقابل نگهداشت.
- **۱۶۴ attribute ی `style="…"`** در `index.html` — استایل پراکنده در ساختار.
- کل CSS محصول **۹۴۶ خط** برای ۳۲ پنل (app.css 645 / chart_pro 177 / symbol.css 124) — سطوح وسیعی از UI بدون استایل می‌ماند و از استایل inline/بی‌قاعده استفاده می‌کند.
- فونت: Vazirmatn باندل شده (۵ وزن: Black/ExtraBold/Bold/Medium/Regular) اما فقط با `--font` عمومی؛ **بدون مقیاس تایپوگرافی، بدون tabular numerals برای اعداد مالی**.
- فقط **۱ قاعدهٔ `:focus`** در کل CSS — بدون سیستم focus قابل مشاهده (WCAG).
- تم تاریک/روشن به‌صورت کلاس `body` + سیستم‌محور هست، اما دو تم از یک توکن مشترک پیروی نمی‌کنند و کیفیت نابرابر دارند.

## ۴. تراکم، سلسله‌مراتب و پیمایش

- تیتربار: لوگو + عنوان + بج نسخهٔ شناور + ۴ تا ۷ چیپ وضعیت با عرض‌های متغیر و متن بریده‌شده (`trust…`، `در حال اتصال…`) — بی‌قاعده در حالت‌های مختلف (`00_home.png` در برابر `chartpro.png`).
- چارت حرفه‌ای: ~۵ ردیف تولبار (نماد، تایم‌فریم، نوع نمودار، اندیکاتور، ابزار رسم + خروجی/ذخیره) پیش از خودِ نمودار؛ تراکم کنترل‌ها بالاست و اولویت بصری صفر (`chartpro.png`).
- جدول دیده‌بان: ۱۳ ستون تخت بدون گروه‌بندی؛ ردیف‌ها چندخطی (~۹۰px) با خوشه‌های برچسب کوچک؛ ستون «دلایل» متن بلند فشرده (`10_home_dark.png`).
- صفحهٔ اصلی پس از جدول تمام می‌شود و ~۳۵٪ پایین صفحه خالی است (`01_home_loaded.png`) — نبود الگوی چیدمان تعریف‌شده.

## ۵. RTL و خوانایی فارسی

- جهت `rtl` و `lang=fa` درست است؛ فونت فارسی Vazirmatn بارگذاری می‌شود.
- اما: اعداد داخل متن فارسی جهت‌به‌هم‌ریخته در ستون «دلایل»؛ ترکیب ٪ فارسی و x لاتین؛ هیچ قاعده‌ای برای `font-feature-settings`/ارقام tabular وجود ندارد.
- برچسب‌های تیتربار/چیپ‌ها گاهی بریده می‌شوند و `title`/aria جایگزین ندارند.

## ۶. دسترس‌پذیری (وضع قبل)

- بدون focus ring سیستماتیک؛ نقش‌های ARIA روی ناوبری اصلی محدود؛ چیپ‌های وضعیت صرفاً رنگ/متن؛ اندازهٔ هدف تعامل در تولبار چارت زیر ۲۴px در مواردی؛ اطلاع‌رسانی وضعیت مالی تا حد زیادی با رنگ (قرمز/سبز) بدون شکل/نشان دوم.

## ۷. اجزای تکراری و CSS پراکنده

- چیپ/بج: حداقل ۴ الگوی متفاوت در تیتربار، بنر، کارت‌ها و جدول.
- دکمه: `btn ghost/primary` + pills متعدد با پدینگ‌های متفاوت در تولبار چارت و فیلترهای صفحهٔ اصلی.
- کارت آماری: دو الگوی متفاوت (دسکتاپ تختِ شناور / کارت‌های تیرهٔ تم تاریک).
- بنر اعتماد داده: یک بنر سراسری + بج‌های تکراری داخل پنل — دو مکانیزم موازی برای یک مفهوم.

## ۹. جمع‌بندی

وضع موجود «قالب داشبوردی عمومی با استایل سطحی» است: پالت ۱۴۸ رنگه، آیکون Emoji، ناوبری مخفی‌شده، نبود stateها، ارقام ناسازگار و CSS کم‌حجمِ پراکنده. این وضعیت با هیچ‌کدام از هشت معیار Apple HIG (Clarity، Deference، Depth، Consistency، Simplicity، Flexibility، Craft، Accessibility) انطباق کامل ندارد و بازطراحی بنیادین (توکن‌محور، کامپوننت‌محور) را ضروری می‌کند — نه اصلاح سطحی CSS.
