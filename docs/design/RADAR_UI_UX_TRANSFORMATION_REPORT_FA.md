**دامنه:** بازطراحی بنیادین هویت بصری و تجربهٔ کاربری کل سایت (۳۲ مسیر) بر پایهٔ RADAR Design System، با الهام از اصول Apple HIG — **بدون تغییر منطق بک‌اند و بدون شکستن هیچ قرارداد تست.**

## ۱. ممیزی اولیه (قبل)

سند کامل: `docs/design/BEFORE_DESIGN_AUDIT_FA.md` + ۱۵ اسکرین‌شات واقعی (`docs/design/evidence/before/`).
مهم‌ترین یافته‌ها: ۲۰/۳۲ تب مخفی (اسکرول ۳۷۷۰px بی‌نشانه)، نبود Skeleton/Empty State، بنر زرد MOOK پرحجم + بج‌های تکراری، آیکون‌های Emoji ناهمگون، ۱۴۸ رنگ یکتا بدون توکن، ۱۶۴ استایل inline، ارقام مخلوط فارسی/لاتین، ۱ قاعدهٔ focus در کل CSS، کنتراست‌های fail (دکمهٔ primary 3.68:1 تیره، سرستون روشن 3.56:1).

## ۲. تصمیم‌های طراحی

1. **توکن‌محوری مطلق** — `tokens.css` منبع یگانهٔ رنگ/تایپو/فاصله/حرکت؛ فایل‌های دیگر فقط مصرف می‌کنند (legacy aliases برای سازگاری).
2. **ناوبری خوشه‌ای** — ۳۲ مسیر در ۶ خوشهٔ منطقی (بازار و دیده‌بانی / تحلیل و ارزش / سیگنال و هشدار / استراتژی و آزمون / هوش و داده / سیستم)؛ دسکتاپ: dropdown، موبایل: bottom-sheet؛ هیچ مسیری مخفی نمی‌ماند؛ خوشهٔ جاری با نشانگر فیروزه‌ای رادار مشخص است.
3. **حذف Emoji از UI کروم** — اسپرایت SVG خطی ۳۵ نمادی (stroke 1.8) + مارک لوگوی رادار؛ متن‌های پین‌شدهٔ تست‌ها دست‌نخورده.
4. **صداقت داده، آرام‌تر** — بنر اعتماد از زرد زننده به نوار کهربایی ظریف با کنتراست AA (10.9:1 تیره / 5.8:1 روشن)؛ محتوای صادقانه (SYNTHETIC/MOCK) حفظ شد — هرگز mock زنده نمایش داده نشد.
5. **اعداد مالی اول** — `tabular-nums` روی همهٔ سلول‌های عددی/کارت‌ها؛ تراز ستونی واقعی برای مقایسه.
6. **Stateها الزامی** — Skeleton شیمر، «در حال دریافت داده…» برای جدول خالی، حالت‌های hover/focus/active/disabled/loading/error برای همهٔ اجزا.
7. **دو تم هم‌کیفیت** — پیش‌فرض light در مارکاپ (حذف FOUC) + تیره؛ هر دو با یک مجموعهٔ کامپوننت.
8. **حرکت کم و هدفمند** — 120/200/320ms فقط روی transform/opacity؛ `prefers-reduced-motion` محترم.

## ۵. نتایج آزمون (واقعی، اندازه‌گیری‌شده)

- **باتری کامل بک‌اند:** 3231 passed / 1 skipped / 0 failed (برابر baseline مرحله اول — صفر رگرسیون).
- **قرارداد فرانت + E2E:** 100/100 (شامل ۱۲ سفر E2E، validator استاتیک ۳۲/۳۲، پین‌های نسخه، shell gates).
- **پویش ۳۲ تب در مرورگر واقعی:** 0 خطای کنسول، 0 خطای صفحه، 0 سرریز افقی (1440/768/390).
- **کنتراست WCAG 2.2 AA** (ترکیب آلفای واقعی، هر دو تم، ۹ نقش): دکمهٔ primary **6.7:1**، بنر اعتماد **10.9:1 (تیره) / 5.8:1 (روشن)**، سرستون جدول **5.06 / 4.69**، برچسب کارت **5.43 / 5.03**، muted **5.98 / 7.26**، چیپ 6.45/5.58، دکمهٔ ghost 7.26/5.93 — سه شکست واقعی قبل از اصلاح ثبت و رفع شد (3.68→6.7؛ 1.94→10.9؛ 3.56→5.06).
- **صفحه‌کلید:** پیمایش Tab با رینگ فوکوس مرئی (سفید+فیروزه‌ای)؛ Esc منوی خوشه را می‌بندد.
- **UX سناریو (S2):** رسیدن به «مرکز فوروارد تست» = ۲ کلیک / 1.7ms (قبل: ۲۰ تب مخفی پشت اسکرول افقیِ بی‌نشانه — عملاً غیرقابل‌کشف).

## ۶. مشکلات باقی‌مانده (صادقانه — وضعیت PARTIAL برای این موارد)

1. **بازطراحی ساختاری اختصاصی پنل‌های تخصصی:** لایهٔ مشترک (توکن/ناوبری/کارت/جدول/state/تم/موبایل) بر همهٔ ۳۲ پنل اعمال شد، اما پنل‌هایی مانند Strategy Lab / Loops / AI Studio فراتر از پوستهٔ مشترک، بازچینی محتوایی اختصاصی نشده‌اند.
2. **pixel-diff خودکار در CI:** before/after انسانی + اندازه‌گیری‌های برنامه‌ای انجام شد؛ خط لولهٔ screenshot-regression خودکار برقرار نشد (ابزار در sandbox نیست) — پیشنهاد: افزودن Playwright visual test به CI.
3. **رندر داخلی canvas نمودار** (رنگ کندل/محور lightweight-charts vendor) تغییر نکرد — عمداً (حفظ دقت مالی و عملکرد)؛ فقط قاب/تولبار/tooltip/دیده‌بان بازطراحی شد.
4. **ممیزی عنصر‌به‌عنوان WCAG برای تمام کنترل‌های ۳۲ پنل** — نقش‌های اصلی سیستمیک اندازه‌گیری شد؛ ممیزی کامل تک‌عنصری گام بعد است.
5. **build-installer CI** (باقی‌ماندهٔ مرحلهٔ دوم) — جداگانه در شواهد push/CI پیگیری می‌شود.
