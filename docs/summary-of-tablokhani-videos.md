### ویدیو 1: aoyrpi6 - سهام رانتی (57 ثانیه)
**خلاصه منطق تدریس شده:**
- رانتی = سهمی که قبل از خبر رسمی، حجم غیرعادی می‌خوره
- فیلتر: حجم 3x میانگین + قدرت خریدار 1.3 تا 3.0 + سرانه >50M + پایانی مثبت ولی آخرین رنج + حقوقی به حقیقی
- مثال: کگل با حجم 398M و قدرت 6.3 و درصد -1.65% - یعنی داره جمع میشه ولی قیمت رشد نکرده

**منطق دقیق برای پیاده‌سازی بهتر:**
```
volume_ratio >= 3
1.3 <= buy_power <= 3.0
pcp > 0.5 and plp < 1.0
buy_per_capita > 50_000_000 and plp < 2
legal_to_individual != 0
```
**بهبود ما نسبت به تابلوخوانی:** تابلوخوانی فقط فیلتر میده، ما دلیل هر سهم رو هم میگیم + ریسک: "خبر رانتی ممکنه سوخته باشه"

### ویدیو 2: dvlux46 - سهم لیدر (4:47)
**خلاصه:**
- هر صنعت یک لیدر داره که اول حرکت می‌کنه
- لیدر: بیشترین ارزش معاملات در صنعت + قوی‌ترین قدرت + اولین مثبت + حجم مشکوک
- اگر لیدر صف خرید شد، بقیه گروه میاد - پس لیدر رو بخر، فالوورها بعدش میاد

**منطق دقیق:**
```
برای هر صنعت cs:
  مرتب بر اساس: tval*0.1 + buy_power*10 + volume_ratio*5 + plp*2
  نفر اول = لیدر اگر tval>5B و buy_power>=1.5 و volume>=1.5 و plp>-1
  2 نفر بعدی = فالوور
```
**بهبود ما:** تابلوخوانی فقط اسم لیدر رو میده، ما میگیم "اگر فملی صف شد، فولاد و کگل بعدش میاد" + جمله سیگنال

### ویدیو 3: mfu10dr - تحرکات بزرگان
**خلاصه:**
- مقایسه تیک الان با 10 دقیقه قبل
- Δ پول خالص، Δ قدرت، Δ حجم، Δ درصد
- امتیازدهی: تغییر شدید خالص + رشد سرانه + پول داغ + تقویت قدرت + شتاب حجم

**منطق دقیق (از big_moves.py شما که الان 74000 ثانیه coverage داره):**
```
delta_net = net_val - old_net
if abs(delta_net) >= 5e9: score += 35
if delta_buy_per_capita >= 50M: score += 18
if delta_hot >=15: score +=15
if delta_buy_power >=0.5: score +=12
...
```
**بهبود ما:** تو الان actual_window_sec و coverage_sec هم نشون میدی که تابلوخوانی نداره - کاربر می‌فهمه پنجره واقعی چند ثانیه بوده

### ویدیو 4: svc1c34 - پول داغ چیست؟ (9:10)
**خلاصه:**
- پول داغ: سرانه خرید حقیقی >200M
- پول داغ پلاس: 100-200M
- یعنی یک حقیقی درشت داره می‌خره - پول هوشمند

**منطق:**
```
per_capita = Buy_I_Volume * pl / Buy_CountI
if per_capita >= 200M: tier = hot
elif per_capita >= 100M: tier = plus
```

### ویدیو 5: wubcg1b - سیگنال‌گیری از پول داغ + سهام مستعد رشد
**خلاصه (مهم‌ترین ویدیو):**
- پول داغ به تنهایی کافی نیست - باید با قدرت خریدار + حجم مشکوک + درصد ترکیب بشه
- سهام مستعد رشد: امتیاز ورود بالا + پول داغ مثبت + حجم مشکوک + قیمت منفی یا کم مثبت (هنوز صف نشده ولی پول داره میاد - کاندید فردا)

**فیلتر دقیق مستعد رشد:**
```
entry_score >=65 and hot_net>10 and volume_ratio>=2 and plp<=1.5
```

**بهبود ما نسبت به تابلوخوانی:** تابلوخوانی فقط پول داغ امروز رو میده، ما فردا رو پیش‌بینی می‌کنیم

### ویدیو 6: zfx61fv - بازی بازار (بزرگان/متوسط/خرد)
**خلاصه:**
- big_player_bias, mid_player_bias, retail_bias
- اگر big_bias مثبت و retail منفی = ورود بزرگان، خروج خرد = سیگنال خرید
- dominant = ورود بزرگان، ورود متوسط، خروج بزرگان

**منطق:**
```
if big_bias > 0.5 and retail_bias < -0.3: dominant = "ورود بزرگان"
if mid_bias > 0.5: "ورود متوسط"
```

**بهبود ما:** فقط اونایی که ورود بزرگان یا ورود متوسط دارن رو نشون بده با جمله "بزرگان دارن می‌خرن"

### امکانات موجود در عکس:
**بالا:**
- پاک کردن کش، ذخیره پورتفایل، ذخیره جدول، به‌روزرسانی - 4 دکمه
- آخرین به‌روزرسانی: 9:15:02
- خلاصه: تعداد کل 1001، مثبت 567، منفی 284، میانگین تغییرات 0.44%، حجم کل 9,283,615,330، ارزش کل 79,561,550 (میلیون)

**وسط:**
- فیلتر صنعت (همه)، انتخاب ستون‌ها (11)، جستجو بر اساس نام یا نماد
- جدول با ستون‌ها (از راست به چپ):
  نماد | حجم | آخرین | درصد آخرین | پایانی | درصد پایانی | تعداد خریدار حقیقی | سرانه خرید | تعداد فروشنده حقیقی | سرانه فروش | نسبت خرید به فروش
- هر ستون یک dropdown فیلتر داره (مثلاً عدد، فیلتر)
- ردیف‌ها: شاکسا، شبنا، دی، خودرو، شبندر، وبصادر، کگل، وتجارت، شیراز، پالوت، وغدیر، شتران، فجر، خکاوه، ونوین

**منطق:**
- هر چند ثانیه رفرش میشه (مثل عکس نوشته "این صفحه هر چند ثانیه یکبار رفرش میشه" در عکس قبلی)
- کاربر می‌تونه ستون‌ها رو شخصی‌سازی کنه (11 ستون انتخاب)
- می‌تونه فیلتر کنه مثلاً سرانه خرید > 100M

**بهبود ما نسبت به تابلوخوانی:**
- تابلوخوانی فقط جدول ساده با فیلتر عددی داره
- ما می‌تونیم:
  1. همین جدول رو با Virtual Scrolling (واکنش‌گرا) بسازیم
  2. خلاصه بالا با تعداد کل، مثبت، منفی، میانگین تغییرات، حجم کل، ارزش کل - همین الان داریم ولی باید مثل عکس دقیق کنیم
  3. دکمه ذخیره جدول به CSV/Excel - تابلوخوانی داره، ما هم اضافه کنیم (قبلاً نداریم)
  4. انتخاب ستون‌ها (11 ستون) - الان ما همه ستون‌ها رو نشون میدیم، باید قابل انتخاب بشه مثل عکس
  5. جستجو بر اساس نام - داریم
  6. هر ستون فیلتر جدا - این رو نداریم، باید اضافه کنیم (مثلاً فیلتر سرانه خرید > 200M)
  7. رنگ‌بندی بر اساس مثبت/منفی - داریم
  8. ذخیره پورتفایل - داریم

**پیاده‌سازی بهتر:**
- از react-virtuoso برای جدول 1001 ردیف (مثل عکس) استفاده کنیم که لگ نزنه
- localStorage برای ذخیره تنظیمات ستون‌ها
- Export to Excel با openpyxl
- فیلتر هر ستون با range slider
