# راهنمای کاربری — شکار سهام

## اجرای برنامه

```bash
cd shekar-saham/backend
pip install -r requirements.txt
export DATA_SOURCE=auto          # در سرور ایران: داده زنده
# export DATA_SOURCE=mock        # فقط دمو
export PYTHONPATH=$(pwd)
python3 -m app.main
```

سپس در مرورگر: [http://127.0.0.1:8000](http://127.0.0.1:8000)

## 🏁 جمع‌بندی نهایی (تابلو + بنیادی + جریان ۱۰دقیقه)

تب **جمع‌بندی نهایی** سهام را این‌طور ترکیب می‌کند:

| لایه | نقش |
|------|-----|
| تابلوخوانی | امتیاز ورود/خروج، قدرت خریدار، حجم |
| بنیادی ارزنده | value_score و P/E |
| جریان ۱۰دقیقه‌ای | تحرکات بزرگان (ورود/خروج پول) |

### هشدار خرید
وقتی **هم‌زمان**:
- بنیادی ارزنده باشد (امتیاز بالا + P/E معقول)
- جریان ۱۰دقیقه‌ای **ورود پول قوی** باشد
- امتیاز ترکیبی از آستانه بخرد

→ در جدول «خرید ⚡» و در **تلگرام/بله** با عنوان «هشدار خرید ترکیبی»

### هشدار فروش
جریان خروجی قوی + ریسک خروج تابلو → «هشدار فروش ترکیبی»

### تنظیم اعلان
تب **اعلان‌ها**:
1. توکن تلگرام/بله + Chat ID
2. «فعال» = بله
3. «هشدار جمع‌بندی نهایی» = فعال
4. حداقل خرید/فروش ترکیبی (پیش‌فرض ۷۰ / ۶۵)
5. دکمه **ارسال هشدارها** در تب جمع‌بندی یا صبر برای رفرش خودکار

```http
GET  /api/confluence
POST /api/confluence/notify-now
```

بدون توکن: dry-run در لاگ اعلان‌ها ثبت می‌شود.

## تحلیل بنیادی ۵محوره و سهام ارزنده

### تب 📊 بنیادی
- لیست نمادها با **امتیاز ارزندگی**
- دکمه **گزارش عمیق** یا کلیک روی ردیف:
  1. روند کلی (۳ دوره + ٪تغییر)
  2. سودآوری (حاشیه، ROA/ROE، غیرعملیاتی)
  3. بدهی و نقدینگی (جاری، آنی، D/E، WC، فشار مالی)
  4. کیفیت سود (CFO در برابر سود خالص)
  5. ۵ قوت / ۵ ریسک / ۵ سؤال + حسابرس

هر بند برچسب دارد: **قطعی / تحلیلی / ناکافی** و مرجع جدول/یادداشت.

### تب 💎 سهام ارزنده
رتبه‌بندی پتانسیل بنیادی با فیلتر حداکثر P/E و حداقل امتیاز.

وزن امتیاز (۰–۱۰۰):
- P/E تا ۳۰
- روند تا ۱۵
- سودآوری تا ۲۰
- نقدینگی/بدهی تا ۱۵
- کیفیت نقد تا ۱۵
- حسابرس تا ۵
- تعدیل کوچک PEG

```http
GET /api/fundamentals/value?max_pe=18&min_score=55
GET /api/fundamental/{نماد}/deep
```

> در حالت فعلی صورت‌های مالی synthetic سازگار با تابلو است تا UI کامل باشد. با اتصال کدال واقعی، همان ساختار با داده definite پر می‌شود و عدد حدسی ساخته نمی‌شود.

## فاز ۴ — لایو، اعلان، بک‌تست، اختیار

### 📡 لایو (WebSocket)
اتصال خودکار به `ws://host/ws/live`. با هر رفرش سرور، overview و سیگنال‌ها push می‌شوند.  
دکمه «درخواست refresh» پیام `refresh` می‌فرستد.

### 📨 اعلان تلگرام / بله
در تب اعلان‌ها:
1. توکن و Chat ID را وارد کنید (یا env)
2. «فعال» را روشن کنید
3. حداقل امتیاز ورود/خروج را تنظیم کنید
4. تست بفرستید

بدون توکن: **dry-run** در لاگ سرور و جدول notify_log.

```bash
export NOTIFY_ENABLED=1
export TELEGRAM_BOT_TOKEN=123:ABC
export TELEGRAM_CHAT_ID=456
# BALE_BOT_TOKEN / BALE_CHAT_ID
```

### 📉 بک‌تست
آستانه ورود/خروج، TP/SL، کارمزد را تنظیم و اجرا کنید.  
اگر تاریخچه DB کافی باشد از آن استفاده می‌شود؛ وگرنه مسیر مصنوعی.

### 🎟 اختیار معامله
نماد را بارگذاری کنید: زنجیره کال/پوت، greeks، پیشنهاد استراتژی (long call، bull spread، put، …) و ماشین‌حساب پرمیوم.

## تب‌ها و صفحات (فاز ۳)

### 🗺 نقشه بازار
Treemap صنایع/نمادها. اندازه: ارزش/حجم/مارکت‌کپ — رنگ: درصد، امتیاز ورود، پول داغ و …

### 🧪 فیلترنویسی
عبارت بولی، مثلاً:
```
plp <= 0 and buy_power >= 1.8 and volume_ratio >= 2 and pe > 0 and pe <= 12
industry contains فلز and entry_score >= 60
```
Presetها را بزنید یا فیلدها را کلیک کنید. فیلتر را ذخیره کنید.

### 📊 بنیادی
رتبه‌بندی بر اساس fund_score، ROE، رشد سود/فروش، بدهی، P/B.

### صفحه نماد
`/symbol?s=فملی` یا دکمه ↗ / دابل‌کلیک روی ردیف:
- نمودار کندل/خطی
- پنج مظنه، حقیقی/حقوقی
- تابلو کستیک، بنیادی فصلی
- پول داغ دقیق از ریزمعاملات

## تب‌ها (فاز ۲)

### ⚡ تحرکات بزرگان
اختلاف پول/حجم/قدرت/قیمت نسبت به ۵–۳۰ دقیقه قبل. فیلتر ورود/خروج پول.

### 📐 تابلو کستیک
D⁺، M⁺، عدد طلایی، درجه کیفیت، الگوی ساعت و تخمین کراس.

### 💼 پورتفو
نمادهای تحت‌نظر. از دکمه ＋ در جداول یا فرم تب پورتفو اضافه کنید.

### 🔔 هشدارها
تاریخچه سیگنال‌های ورود/خروج ثبت‌شده در DB.

### ⚙️ تنظیمات
آستانه‌های موتور (پول داغ، حجم، امتیاز ورود/خروج، پنجره تحرکات) را تغییر و ذخیره کنید.

### 🎯 شکار ورود
مهم‌ترین صفحه. نمادهایی که امتیاز ورود‌شان از آستانه (پیش‌فرض ۶۵) بالاتر است.

**فیلترها:**
- فقط قیمت منفی → الگوی «جمع‌آوری در منفی قبل از صف»
- فقط بنیادی خوب → P/E جذاب/قابل قبول
- حداقل امتیاز → سخت‌گیری سیگنال

**چطور استفاده کنید (مطابق آموزش‌های تابلوخوانی):**
1. صبح با تب شکار ورود و پول داغ شروع کنید.
2. نمادهای مشترک بین «ورود» و «پول داغ خرید» را جدا کنید.
3. روی ردیف کلیک کنید تا جزئیات سرانه، قدرت، صف و بنیادی را ببینید.
4. اگر سهم در منفی است + حجم مشکوک + قدرت خریدار بالا → اولویت بالاتر.
5. قبل از ورود، مقاومت/حمایت را خودتان هم چک کنید.

### 🚪 هشدار خروج
وقتی در سهم هستید یا رصد می‌کنید:
- خروج پول حقیقی
- ضعف قدرت خریدار
- فروش درشت / پول داغ منفی
→ کاهش موقعیت یا خروج پلکانی را بررسی کنید.

### 🔥 پول داغ
معاملات/سرانه درشت حقیقی (مشابه منطق سایت تابلوخوانی).

### 🎲 بازی بازار
ببینید ورود از سمت بزرگان است یا خردها (ورود خرد بدون بزرگان معمولاً ضعیف‌تر است).

### 🏭 شکار صنعت
اگر صنعت داغ باشد، لیدر همان صنعت را از تب ورود جدا کنید.

## اتصال داده واقعی

روی VPS/سیستم با دسترسی به اینترنت ایران:

```bash
export DATA_SOURCE=tsetmc
# یا
export DATA_SOURCE=brsapi
export BRSAPI_KEY=کلید_شما
export POLL_SECONDS=20
```

اگر `auto` بگذارید، به ترتیب TSETMC → BrsApi → Mock امتحان می‌شود.
