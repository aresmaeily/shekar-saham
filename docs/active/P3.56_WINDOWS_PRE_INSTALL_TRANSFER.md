## 5. After owner says INSTALL (not now)

Only then, on Windows:

1. Copy `.env.example` to `.env` if needed and edit secrets locally.
2. Set `DATA_SOURCE`, and if required `PRIVATE_MODE` / `PRIVATE_PASSWORD` / `API_KEY` / `FERNET_KEY`.
3. Do not set a fabricated `BRSAPI_KEY`.
4. Run `scripts/windows/install.ps1`.
5. Run `scripts/windows/start.ps1`.
6. Run `scripts/windows/validate_alpha.ps1`.
7. Inspect `/api/live/status` and `data_trust`. mock/fallback/synthetic is **not** live.

Electron (optional, not required for backend alpha):

```text
RADAR_BOURSE_URL || SHEKAR_URL || http://127.0.0.1:8000
```

`SHEKAR_URL` is a legacy environment fallback only.
