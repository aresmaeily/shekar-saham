## Objective

Implement the first deterministic AI Intelligence Core as a central evidence aggregation layer for Iran-market decision support. This is not a chatbot upgrade and not autonomous trading.

## What was implemented

- `backend/app/domain/ai_intelligence.py`
- `AIIntelligenceCore`
- `IntelligenceEvidence`
- `IntelligenceResult`
- deterministic confidence and recommendation mapping
- conflict detection
- data-trust hard gate
- API integration: `POST /api/ai/intelligence/{symbol}`
- tests for evidence aggregation, conflicts, data trust blocking, unavailable data, service integration and API smoke

## What was not implemented

- Live LLM provider
- AI Research Agent
- Multi-agent system
- autonomous trading
- broker integration
- production strategy mutation
- global market expansion
- frontend UI redesign

## Data Trust Behavior

If `data_trust.state` is `mock`, `synthetic`, `stale`, or `unavailable`, the AI Intelligence Core blocks actionable live recommendations and returns `INSUFFICIENT_DATA` with warnings/invalidations.

## Recommendation Contract

```text
BUY_CANDIDATE
HOLD
SELL_CANDIDATE
WATCH
NO_ACTION
INSUFFICIENT_DATA
```

Each result includes:

```text
symbol, market, timestamp, data_trust, market_regime,
technical_score, fundamental_score, money_flow_score, filter_score,
strategy_score, risk_score, confidence, recommendation,
evidence, warnings, invalidations, reasoning_summary, reason_codes, conflicts, safety
```

## Safety

- No guaranteed profit.
- No price prediction guarantee.
- No autonomous trading.
- No broker orders.
- No production filter/strategy mutation.
- Data Trust gate is applied before actionable recommendation.
