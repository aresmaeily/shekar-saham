# P3.64 — Market Intelligence Session Status

Date: 2026-08-15

P3.64 wires the existing P3.63 Iran TSE session inference into the existing P3.40 `MarketIntelligenceSnapshot.market_status` field. This is an integration of two already-documented contracts, not a new product feature.

## Source

```text
docs/architecture/IRAN_MARKET_DATA_DOMAIN.md — MarketSession + remaining session/data-trust rules
backend/app/domain/market_intelligence.py — MarketIntelligenceSnapshot.market_status (default open_unknown)
docs/active/P3.40_MARKET_INTELLIGENCE_CONTINUOUS_MONITORING_FINAL_REPORT.md — snapshot includes market_status
docs/active/P3.63_IRAN_MARKET_SESSION_INFERENCE_REPORT.md — weekday + Asia/Tehran inference
```

## Why this task

After P3.63, `infer_iran_market_session()` existed and `/api/status` exposed `market_session`, but Market Intelligence still emitted `market_status=open_unknown`. That field is part of the P3.40 snapshot contract. Filling it does not add a scheduler, UI, holiday calendar, or live-data claim.

## Behavior

```text
market_status = infer_iran_market_session().status
values: pre_open | open | closed
holiday: never emitted
Session-open does not set data_trust.is_live
```
