# P3.75 — Data Trust Hardening

Date: 2026-08-15

Independent `live_verified` is now part of the canonical trust context. Source label and freshness cannot create verified LIVE. Missing 30-day volume is unknown, not a fabricated historical average.

## LIVE contract

```text
verified LIVE =
  state == live
  AND is_live == true
  AND live_verified == true

live_verified is never inferred from source or timestamp.
```

## S0-1

`build_data_trust_context()` now emits `live_verified` (default false). `is_live` is true only when `live_verified` is explicitly true and state remains live after freshness checks.

## S0-2

TSETMC/BRSAPI mappings no longer compute `avg_vol_30d` from `bvol`/`tvol`. Metrics treat missing average as unknown (`volume_ratio=0`).
