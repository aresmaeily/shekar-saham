Findings:

1. A legacy backtest engine existed in `backend/app/engines/backtest.py`.
2. Existing `/api/backtest/run` was already present and used threshold-based entry/exit parameters.
3. Historical data is sourced from SQLite ticks via `store.get_ticks_since`; synthetic fallback is used when history is insufficient.
4. P3.26 Strategy Framework existed but did not yet have a backtest consumer.
5. Existing backtest did not explicitly model next-bar execution, slippage, portfolio capital or walk-forward/forward-test separation.
6. P3.27 needed additive changes preserving the existing endpoint and threshold behavior.

## H — Walk-Forward Test

Added rolling train/test window evaluation:

```text
train_bars → test_bars → roll by step_bars
```

Important boundary:

```text
Train indexes are excluded from each test slice.
```

P3.27 does not optimize parameters during training; it only enforces out-of-sample test execution.

## I — Forward Test

Added simulated forward-test boundary:

- explicit `start_ts`, or
- default later segment using last third of the dataset

This is out-of-sample simulated execution only, not live paper trading.

## J — Strategy / Filter Integration

P3.26 `FilterStrategy` now has a backtest consumer.

Flow:

```text
Filter DSL expression
  ↓
FilterStrategy
  ↓
StrategySignal
  ↓
run_filter_strategy_backtest
```

Existing threshold behavior is preserved through generated filters:

```text
entry_score >= <entry_threshold>
exit_score >= <exit_threshold>
```

## K — Quant Safety

Implemented/validated:

- Entry signal uses bar `t`, execution occurs at bar `t+1`.
- Exit filter uses bar `t`, execution occurs at `t+1` when available.
- Future candle is not used for the entry decision.
- Walk-forward train/test indexes are separated.
- Forward test uses later boundary.
- `data_trust` is included in reports.

Limitations:

- Real market microstructure, queues, partial fills and liquidity constraints are not modeled.
- Survivorship bias remains not fully verifiable with current historical data universe.
- Live data validation was not executed.
