# P3.59 — Filter Intelligence Performance / Compare View

Date: 2026-08-14

P3.59 adds a read-only performance and version-comparison view to the existing هوش فیلتر tab. It uses existing Filter Intelligence APIs. It does not activate versions, deploy proposals, schedule work, or claim live data.

## APIs used

```text
GET /api/ai/filters
GET /api/ai/filters/compare?filter_id=&left_version=&right_version=
GET /api/ai/filters/{filter_id}/performance?evaluate=false
```

No new backend engine. No production mutation.
