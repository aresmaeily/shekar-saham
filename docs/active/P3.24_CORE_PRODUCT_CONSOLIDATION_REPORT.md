## G — Data Trust

P3.24 locks the trust terminology:

| Trust state | Meaning |
|---|---|
| LIVE | Validated live provider data. |
| MIXED | Live plus fallback/unknown/partial trust. |
| MOCK | Development/demo generator or mock fallback. |
| SYNTHETIC | Generated/simulated values, not validated live market data. |

Evidence paths:

- `backend/app/core/config.py` — trust-level resolution
- `backend/app/data/providers.py` — TSETMC/BRSAPI/mock fallback provider flow
- `backend/app/data/mock_market.py` — mock market generator
- `backend/app/engines/data_quality.py` — data quality scoring
- `backend/app/services/market_service.py` — source/trust propagation

P3.24 does not claim live TSETMC/BRSAPI validation. Live data validation remains a production gap until executed in a suitable environment.
