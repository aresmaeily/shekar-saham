## Architecture Changes

P3.39 adds a deterministic AI Intelligence Core that consumes controlled market/symbol/filter/backtest context and produces a structured intelligence result.

```text
Market/Domain Context
  ↓
Filter / Strategy / Backtest Evidence
  ↓
Data Trust Gate
  ↓
AIIntelligenceCore
  ↓
Structured IntelligenceResult
  ↓
API / Future UI
```

## AI Intelligence Contract

## Evidence Model

Evidence is represented with:

```text
category, name, value, score, weight, direction, source, note
```

Categories currently include:

- technical
- fundamental
- money_flow
- filter
- strategy
- risk

## Confidence Model

Confidence is deterministic and based on:

- data trust cap
- evidence completeness
- conflict penalty
- risk penalty

Non-live data caps confidence and may block actionable recommendations.

## Conflict Detection

The core detects conflicts such as:

- technical positive but money flow weak
- technical positive but fundamental weak
- entry and exit pressure both elevated
- filter triggers but strategy/backtest evidence weak

Conflicts reduce confidence and can shift recommendation to `WATCH` or `NO_ACTION`.

## Recommendation Model

Recommendations are limited to:

```text
BUY_CANDIDATE
HOLD
SELL_CANDIDATE
WATCH
NO_ACTION
INSUFFICIENT_DATA
```

Non-live data trust states (`mock`, `synthetic`, `stale`, `unavailable`) block actionable live recommendations and return `INSUFFICIENT_DATA`.

## Data Trust Behavior

The Data Trust gate is mandatory. The AI Intelligence Core never treats mock/synthetic/stale/unavailable as live.

Observed API smoke in current environment:

```text
data_trust.state = mock
trust_level = synthetic
recommendation = INSUFFICIENT_DATA
confidence = 0.35
```
