# P3.58 — Filter Intelligence UI Approval Workflow

Date: 2026-08-14

P3.58 implements the P3.41-deferred operator UI for Filter Intelligence human review. It does not rewrite architecture, activate filters automatically, claim live data, install on Windows, or synchronize GitHub.

## Objective

Close the documented gap:

```text
Backend review API exists
UI approval workflow was DEFERRED
```

## Implementation

- New dashboard tab `filter-intel` / هوش فیلتر
- Load registry from `GET /api/ai/filters`
- Load proposals from `GET /api/ai/filter-proposals`
- Optional create via existing `GET /api/ai/filter-proposals?filter_id=...`
- Review via `POST /api/ai/filter-proposals/{id}/review` with APPROVE / REJECT / REQUEST_RETEST
- Data-trust display never says LIVE unless `state=live` and `is_live=true` and `live_verified=true`

## Safety

Approval does not change `active_version`. Production mutation remains false. Scheduler and automatic deployment remain deferred.
