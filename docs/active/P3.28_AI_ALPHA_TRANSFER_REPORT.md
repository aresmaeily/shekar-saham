Findings:

5. Filter DSL and Backtest outputs can be explained or optimized, but no automatic changes are allowed.
6. Alpha requires transfer artifacts and setup instructions because GitHub closure is pending.

## G — AI Assistant

Endpoint:

```text
POST /api/ai/assistant
```

Purpose:

- explain current market context
- explain symbol context
- explain filter output
- explain backtest context if provided
- explain data trust and uncertainty

If context is insufficient, it returns an Insufficient Data-style warning rather than inventing facts.

## H — AI Analyst

Endpoint:

```text
POST /api/ai/analyze
```

Structured output includes:

- market context
- symbol context
- key observations
- risk flags
- uncertainty
- evidence
- conclusion/summary
- data trust
- confidence

No guaranteed signal or price prediction is produced.

## I — AI Optimizer

Endpoint:

```text
POST /api/ai/optimize
```

Allowed behavior:

- suggest filter relaxation/tightening
- suggest scenario/backtest review
- point out weak profit factor or high drawdown from supplied backtest result
- preserve manual approval boundary

Explicitly not allowed:

- auto trading
- broker orders
- automatic strategy modification
- repository/file changes
- automatic commits
