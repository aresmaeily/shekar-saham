## Repairs performed

### P2 — Public probe leak / cookie gap

`/api/health` already redacted unauthenticated market stats, but:

- it did not accept the HttpOnly session cookie as authorization
- `/api/status` and `/api/live/status` returned full market/confluence/notifier payloads when `AUTH_REQUIRED=1`
- `private_mode` middleware 401'd those probe routes even though they are documented public paths

Fix:

- `request_is_authorized()` now checks API key, Bearer, and cookie
- probe handlers redact confluence, notifier chat IDs, store, flow, WS, and symbol counts unless authorized
- middleware honors `is_public_path` in private mode so probes stay reachable and redacted
- `data_trust` remains on redacted probes and is never verified LIVE

### P2 — Electron origin lock

`electron/main.js` blocked `window.open` but allowed in-window navigation to any URL.

Fix: `will-navigate` and `will-redirect` are restricted to the configured `RADAR_BOURSE_URL || SHEKAR_URL` origin. External URLs open in the OS browser. `SHEKAR_URL` fallback is preserved.
