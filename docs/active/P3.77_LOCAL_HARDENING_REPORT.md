# P3.77 — Local Hardening and Defect Closure

Date: 2026-08-15

Independent post-P3.76 re-audit of the local repository. This phase repaired remaining locally fixable trust, notifier, frontend, and production-security defects. No Alpha, install, live provider, or GitHub push was performed.

## LIVE contract (unchanged)

```text
verified LIVE =
  state == live
  AND is_live == true
  AND live_verified == true

live_verified is never inferred from source, timestamp, freshness,
TRUST_LEVEL, fetch success, or a caller argument.
```

## Local repairs

- Notifier no longer treats `trust_level=live` as verified LIVE.
- `/api/confluence/notify-now` now passes `data_trust` and blocks unverified data unless synthetic is explicitly allowed.
- `MarketService.trust_level()` after refresh stores the canonical context level, not source classification.
- `_build_confluence` and WS refresh include `data_trust`.
- Forex API no longer maps yahoo/binance/okx source labels to `trust_level=live`.
- Forex and legacy UI cannot display verified LIVE without the triple gate.
- Auto-refresh button wording is `خودکار` (polling on), not LIVE data.
- Production requires `COOKIE_SECURE=1`.
- Wildcard CORS is rejected in production even if `DEBUG=1`.
- Backtest metrics document Sharpe as per-trade / not annualized.

## Deferred / not repaired

- Same-bar TP/SL uses decision-bar close. Intra-bar high/low model is an engine contract change.
- Walk-forward remains rolling OOS of a fixed filter, not parameter optimization.
- Official TSE holiday calendar.
- Frontend `fetch` outside `core/api.js` (documented debt, no auth bypass found).
- Starlette TestClient deprecation warning requires `httpx2` (dependency upgrade not authorized).

## Not started

- Real TSETMC/BRSAPI live verification
- Windows / Electron / Browser E2E
- GitHub push
- Installation / Alpha launch
